# Agent-Ready Stack Skills

A set of Pi skills for improving software systems so coding agents can understand, verify, modularize, migrate, and rewrite them safely.

## Skills

- `/skill:agent-ready-map` — map dependencies, boundaries, shared state, and operational knowledge.
- `/skill:verification-layer` — add characterization, contract, integration, and end-to-end verification.
- `/skill:headless-split` — separate domain/data capabilities from UI through stable contracts.
- `/skill:boundary-redraw` — choose and implement clearer module or service boundaries.
- `/skill:strangler-migration` — migrate capabilities incrementally behind a stable seam.
- `/skill:bounded-rewrite` — replace a bounded component using the existing system as an oracle.

Each skill is deliberately evidence-driven: inspect first, state assumptions, make bounded changes, and leave durable artifacts for the next agent.
